# UniSphere

UniSphere is a Flutter-based campus platform for discovering university events, clubs, and announcements.

## Tech Stack

- Flutter
- Dart
- Cubit / BLoC
- REST API
- Firebase Authentication

## Features

- User authentication
- Event discovery and search
- Event creation and management
- Event RSVP
- Club discovery and membership
- User profile

## Backend

UniSphere communicates with a Spring Boot REST API backed by PostgreSQL.

The backend is maintained as a separate project alongside the Flutter application.
